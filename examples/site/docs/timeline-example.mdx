# TimelineExample

`TimelineExample` takes a JSON Schema for a
[jspsych-timelines](https://github.com/jspsych/jspsych-timelines) package's
options and runs the package with them in a sandboxed iframe, then shows the
resulting data. The options are edited as **text** (JSON5: comments, unquoted
keys and trailing commas are fine) in a code editor that shows only the values
that differ from the defaults, with autocomplete, hover help and inline
validation. "Show all parameters" expands the editor to every option, grouped,
with defaults dimmed; "Hide defaults" collapses it again. A secondary **Form**
tab offers the same options as a generated form. This page exercises it three
times.

## Flanker (real package)

The schema is hand-written for the existing flanker package
(`createTimeline(jsPsych, FlankerOptions)`), and the bundle is the package's
IIFE build, copied into `static/timelines/`. Pick the "Quick demo" preset, press
Run, and respond to a few trials. This one has `syncToUrl` on, so the options
are in the URL hash and can be shared.

<TimelineExample
  schema={flankerSchema}
  bundle="/timelines/flanker.browser.js"
  globalName="jsPsychTimelineFlanker"
  syncToUrl
  hashKey="flanker"
  height={460}
/>

## Synthetic schema (all widgets)

Covers what flanker doesn't: duration jitter, map editors, a bundle sub-form,
phase overrides, advanced fields, nullable limits, a JSON-editor fallback, and
the `renderFieldExtra` and `onRunComplete` extension points (here the extra
column shows the field's `x-jspsych.evidence`, and the completed run is logged
to the console). The "task" is a mock that echoes the options it received.

<TimelineExample
  schema={syntheticSchema}
  bundle="/timelines/mock-timeline.js"
  globalName="jsPsychTimelineMock"
  dependencies={['@jspsych/plugin-html-button-response@2.1.0']}
  hashKey="synthetic"
  renderFieldExtra={(name, propertySchema, value) => {
    const evidence = propertySchema['x-jspsych']?.evidence;
    if (!evidence) return null;
    return (
      <div data-testid="field-extra">
        <strong>Evidence:</strong>{' '}
        {evidence.map((e) => `${e.study} used ${e.value}`).join('; ')} (current: {String(value)})
      </div>
    );
  }}
  onRunComplete={(data) => console.log('TimelineExample run complete', data)}
/>

## Flanker, full 34-option schema (code view, presets)

The real generated schema for the flanker package, with its 17 study presets.
Choose a preset: the editor shows only what that study set, and its
description sits under the dropdown. Toggle "Show all parameters" to see
everything, with the preset's values marked `// preset`.

<TimelineExample
  schema={flankerFullSchema}
  bundle="/timelines/flanker-full.browser.js"
  globalName="jsPsychTimelineFlanker"
  hashKey="flankerfull"
  initialOptions={{n_test_trials: 8, practice_trials: 0}}
/>
